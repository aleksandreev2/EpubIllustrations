# Демонстрационные книги

Выполните `npm run demo`, чтобы создать две небольшие EPUB-книги в `examples/generated/`.
Они содержат вымышленные названия глав и оригинальные векторные пейзажи, созданные
для проверки этого приложения. Пользовательские книги и сторонние иллюстрации
в примерах не используются.

Генератор и иллюстрации распространяются по [MIT](../LICENSE). Эти же книги
используются на скриншотах в README.
