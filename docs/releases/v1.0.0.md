Первый публичный выпуск **«Иллюстрации EPUB»** — приложения команды **Дом Некроманта**.

Добавьте EPUB, выберите иллюстрации и сохраните их в папку или ZIP. Встроенные
картинки копируются без пережатия; прямые HTTPS-ссылки, в том числе NovelPia
`.file`, загружаются с определением настоящего формата.

В просмотрщике доступны масштаб колесом, перемещение мышью, поворот,
перелистывание, режим 100% и сведения об исходнике. Обложки выбираются отдельно.

### Скачать

- **EpubIllustrations-1.0.0-Setup.exe** — обычная установка с ярлыками.
- **EpubIllustrations-1.0.0-Portable.exe** — запуск без установки.
- **SHA256SUMS.txt** — контрольные суммы SHA-256.

Windows 10/11 x64. Node.js и Python для готовых сборок не нужны.
