Теперь можно задавать собственное имя папки каждой книги перед сохранением.

- Выберите книгу и нажмите **«Имя папки»** над галереей, либо карандаш рядом с книгой в библиотеке.
- Введите название и нажмите **«Сохранить»**. У книг с одинаковыми заголовками могут быть разные папки, например «Первый том» и «Второй том».
- Имя запоминается после перезапуска и работает для **папки и ZIP** во всех трёх режимах структуры.
- **«Название книги»** возвращает автоматическое имя. Приложение проверяет недопустимые имена Windows и показывает будущую папку до сохранения.
- В истории видны имена папок, использованные в новых экспортах.
