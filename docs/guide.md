# Руководство

[Скачать приложение](https://github.com/aleksandreev2/EpubIllustrations/releases/latest) · [На главную](../README.md)

## Добавить книги

Нажмите **«Добавить EPUB»** и выберите один или несколько файлов. Можно также
перетащить их из Проводника в окно. Список книг находится слева; **«Все книги»**
возвращает общую галерею. Крестик убирает книгу из текущего списка приложения,
не удаляя исходный файл или историю сохранений. Библиотека и выбор иллюстраций
сохраняются между запусками. Если исходник был перемещён, выберите книгу и нажмите
**«Найти EPUB»**.

Отметки временно недоступной книги сохраняются и вернутся при восстановлении
того же EPUB. Пока исходник недоступен, эти отметки не входят в экспорт.
Если содержимое книги изменилось, приложение сообщает об этом и отмечает
иллюстрации глав новой версии заново.

## Найти и выбрать картинки

Введите название главы или книги в поиск. Фильтры позволяют оставить выбранные
изображения, картинки внутри EPUB, изображения по ссылкам или обложки.

Флажок на картинке включает её в экспорт. **«Выбрать видимые»** отмечает текущий
результат поиска и фильтров, **«Снять выбор»** очищает весь выбор. Обложки по
умолчанию не отмечаются; их можно сохранить вручную.

## Большой предпросмотр

Нажмите на изображение. Внизу видны его исходное разрешение, формат и размер,
а также путь внутри EPUB или адрес прямой ссылки.

| Действие | Мышь или клавиша |
| --- | --- |
| Приблизить и отдалить | Колесо мыши; кнопки `+` и `−`; клавиши `+` и `-` |
| Переместить картинку | Удерживать левую кнопку и перетаскивать |
| Уместить в окно | Кнопка «Уместить» или клавиша `0` |
| Исходный размер | Кнопка «100%» |
| Переключить исходный размер и размещение в окне | Двойной щелчок по изображению |
| Повернуть на 90° | Кнопки поворота; клавиша `R` поворачивает вправо |
| Предыдущая и следующая | Кнопки по краям изображения или стрелки влево/вправо |
| Закрыть | Крестик или `Esc` |

Изображения перелистываются в порядке текущей галереи. Масштаб и поворот
относятся к просмотру. Формат и качество экспорта задаются отдельно.

## Сохранить в папку

В поле **«Структура для каждой книги»** доступны три режима. Они действуют
и для папки, и для ZIP:

- **По папкам-главам** — внутри книги отдельная папка каждой главы.
- **Все в одной папке** — все изображения книги лежат рядом; номер и название главы входят в имя файла.
- **Оба варианта** — две полные структуры в подпапках **«По главам»** и **«Все иллюстрации»**.

Режим запоминается. В варианте «Оба» число физических файлов вдвое больше числа
иллюстраций; изображение загружается и при необходимости преобразуется один раз,
затем один и тот же результат сохраняется в обе структуры.

Внизу окна отображается выбранная папка. Нажмите **«Изменить»**, чтобы выбрать
другую; приложение запомнит её. **«В папку»** сохраняет отмеченные изображения
в подпапки книг и глав. Повторяющиеся имена получают суффикс `(2)`, `(3)` и далее.

Папка по умолчанию: `Рабочий стол/вытянуть иллюстрации новелпиа`.

```text
Название книги/
  0000 Обложка/
    001.jpg
  0003 Название главы/
    001.webp
    002.png
  9999 Вне глав/
    001.svg
```

Число в имени папки соответствует порядку документа внутри EPUB. Титульные
страницы и служебные документы тоже могут занимать позиции, поэтому оно может
отличаться от номера главы в её заголовке. Изображения без привязки к тексту
попадают в **«Вне глав»**.

## Сохранить ZIP

Нажмите **«В ZIP»**, выберите имя и место для архива. Структура внутри будет
такой же, как при сохранении в папку. Готовый ZIP можно распаковать средствами
Windows. Кнопка **«Показать результат»** в уведомлении открывает его расположение.

## Качество и ссылки

Нажмите **«Формат и качество»** внизу окна, выберите режим и нажмите **«Применить»**.
Варианты одинаковы для папки и ZIP:

| Формат | Когда выбирать |
| --- | --- |
| Оригинал | Нужен исходный файл без изменений, с анимацией и метаданными |
| WebP | Нужен небольшой вес; начните с качества 85% |
| JPEG | Нужна совместимость с программами; прозрачность заменится белым фоном |
| PNG | Нужны пиксели без дополнительного сжатия с потерями |

У WebP и JPEG качество меняется от 1 до 100. Ограничение длинной стороны
до 3840, 2560, 1920 или 1280 пикселей уменьшает крупные изображения с сохранением
пропорций и не увеличивает маленькие. По умолчанию выбран оригинал; настройки
запоминаются после перезапуска. При преобразовании сохраняется первый кадр
анимации и удаляются метаданные. Потерянные до создания EPUB детали не восстанавливаются.

История показывает формат, качество, ограничение размеров и уменьшение веса,
если результат получился легче исходника. Уже сжатая картинка может не стать легче.

Для ссылок NovelPia с расширением `.file` формат определяется по содержимому:
сохранённый файл получит `.png`, `.jpg`, `.webp` или другое подходящее расширение.
Недоступные ссылки отмечаются ошибкой, остальные изображения сохраняются.
После неудачной загрузки повторный предпросмотр или экспорт обращается к ссылке заново.

## История сохранений

Раздел **«История»** слева показывает завершённые экспорты. У каждой записи
видны дата, книги, выбранная структура, число изображений и файлов, путь вывода.
Частично успешные сохранения также содержат список недоступных иллюстраций.

**«Показать результат»** открывает каталог или выделяет ZIP в Проводнике.
**«Открыть EPUB»** загружает исходные книги этой операции в галерею. Если результат
перемещён или удалён, путь останется в истории, а приложение сообщит, что он недоступен.

История и книги хранятся локально в настройках приложения. Сохранения,
сделанные версией 1.0.0, автоматически задним числом не добавляются.

## Обновить приложение

Автоматическая проверка включена по умолчанию в готовой сборке. Приложение
проверяет GitHub при запуске и раз в шесть часов, пока открыто; повторные проверки
используют кеш. Новая версия появляется в полосе уведомления над галереей.
Если окно неактивно, Windows также может показать системное уведомление.

Нажмите **«Что нового»**, чтобы открыть описание релиза, или **«Обновить»**.
После загрузки и проверки файла приложение закроется. Проверяются размер
и SHA-256 опубликованной сборки.
При ошибке проверки файл не запускается.

Установленная версия запускает установщик. Переносимая версия ждёт завершения
приложения, заменяет исходный EXE и открывается снова. Папка и имя переносимого
файла сохраняются, поэтому номер в его имени может отличаться от фактической
версии в **«О приложении»**. При невозможности замены исходный файл остаётся на месте.

Библиотека, история, выбранные иллюстрации, папка вывода и настройки сохраняются.
Исходные EPUB должны оставаться на своих местах; для перемещённой книги можно
указать новый путь через «Найти EPUB».

В **«О приложении → Обновления»** доступны ручная проверка и переключатель
автоматических проверок. При отключённой автоматике ручная проверка работает.
Крестик в уведомлении скрывает напоминание об этой версии; ручная проверка
возвращает его. При отсутствии интернета или ограничении GitHub можно проверить
позже — встроенные изображения продолжат обрабатываться локально.

В версии 1.0.0 обновляющего модуля ещё нет: для первого перехода скачайте
[1.1.0 или новее](https://github.com/aleksandreev2/EpubIllustrations/releases/latest) вручную.
