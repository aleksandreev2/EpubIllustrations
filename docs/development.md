# Разработка и выпуск

## Окружение

Node.js 22.4+ и npm. `package-lock.json` фиксирует зависимости. Windows-сборка
создаётся на Windows; пользователю готового приложения Node.js не нужен.

```bash
npm ci
npm test
npm start
```

## Структура

| Файл | Назначение |
| --- | --- |
| `src/main.js` | Окно Electron, диалоги, загрузка ссылок, запись результатов и настройки |
| `src/preload.js` | Ограниченный API между интерфейсом и главным процессом |
| `src/epub.js` | Порядок EPUB spine, HTML-ссылки, вложенные изображения, обложки |
| `src/export.js` | Безопасные имена, определение формата, структура экспорта и ZIP |
| `src/renderer.js` | Галерея, выбор, предпросмотр, масштаб, поворот, авторство |
| `src/viewer-math.js` | Геометрия размещения и масштабирования |
| `tests/` | Проверки без пользовательских книг и без сети |
| `scripts/create-demo.cjs` | Исходные демонстрационные книги и иллюстрации |
| `scripts/capture-screenshots.cjs` | Снимки работающего Electron через локальный Chromium DevTools Protocol |

Интерфейс написан на HTML/CSS/JavaScript. Node.js в renderer отключён;
включены изоляция контекста, sandbox и Content Security Policy. Названия книг
и глав добавляются в DOM как текст. EPUB не исполняется как веб-страница.

Сканер читает изображения из `img`, SVG `image`, ссылок на изображения и
неиспользованных файлов картинок. Для сетевых изображений нужен публичный HTTPS;
есть ограничение 30 МБ, тайм-аут и проверка содержимого ответа. Приложение не
передаёт cookies сайта и не выполняет вход в аккаунт.

## Демоматериалы и скриншоты

```bash
npm run demo
npm run screenshots
```

Первый скрипт создаёт книги в `examples/generated/`, второй — четыре снимка
в `docs/images/`. Он запускает временный экземпляр приложения с локальным
портом отладки, загружает только эти книги, проверяет просмотрщик и авторство,
затем завершает экземпляр. Для снимков используется вымышленная папка вывода.

## Сборка Windows

```bash
npm run dist
npm run checksums
```

В `dist/` появятся:

- `EpubIllustrations-1.0.0-Setup.exe` — установщик NSIS с выбором папки;
- `EpubIllustrations-1.0.0-Portable.exe` — версия без установки;
- `SHA256SUMS.txt` — контрольные суммы файлов.

Номер в именах берётся из `package.json`. Дистрибутив включает Electron,
fflate и сведения об их лицензиях. Персональные книги, скриншоты из реальных
библиотек и локальные настройки в сборку не включаются.

## Публикация

1. Обновить версию и `CHANGELOG.md`, выполнить тесты и собрать оба EXE.
2. Проверить запуск готового приложения, README и скриншоты.
3. Создать и отправить тег вида `v1.0.0`.
4. Опубликовать GitHub Release с установщиком, переносимой версией,
   `SHA256SUMS.txt` и описанием изменений.

Также доступен ручной workflow **Windows release**: он принимает существующий
тег, повторяет тесты и сборку на Windows runner, затем создаёт или обновляет
соответствующий релиз. Обычные push и Pull Request запускают только проверки.
